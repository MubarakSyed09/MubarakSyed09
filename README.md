## 🚀 Featured Projects

### [Scholarship Scheme Finder](https://github.com/MubarakSyed09/Scholarship-Scheme-Finder-)
Full-stack web application helping Indian students discover government scholarship schemes they are eligible for. Features a personalized eligibility engine, hierarchical priority sorting, and direct links to official portals.

**Stack:** Java · Spring Boot · Spring Data JPA · REST API · React 19 · TypeScript · Tailwind CSS · Vite · H2

---

### [Weather AI Agent](https://github.com/MubarakSyed09/Weather-AI-Agent)
AI-powered weather assistant that integrates real-time weather data from OpenWeatherMap with LLM-based natural-language interaction using Google Gemini and Ollama tool-calling.

**Stack:** Python · Flask · Google Gemini API · Ollama · OpenWeatherMap API

---

### [DSA with Java](https://github.com/MubarakSyed09/DSA-with-Java)
Structured repository of Data Structures and Algorithms implemented in Java — organized by topic with time and space complexity notes. Built for interview preparation and consistent practice.

**Stack:** Java · Data Structures · Algorithms · LeetCode Practice

---

### [AuraID Advanced](https://github.com/MubarakSyed09/AuraID-Adv)
Digital student credential studio with a React/Vite frontend and a Node.js backend. Features credential creation, photo upload, and an admin dashboard. Deployed on Netlify.

**Stack:** JavaScript · React · Vite · Node.js · Netlify

---

### [Hostel Food Voting System](https://github.com/MubarakSyed09/Hostel-Food-Voting-System)
Python desktop application for hostel mess food selection. Features QR-based student voting, role-based portals for students, cooks, and admins, with a SQLite database backend.

**Stack:** Python · CustomTkinter · SQLite · OpenCV · QR Code · Matplotlib
